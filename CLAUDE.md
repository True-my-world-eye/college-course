## Overview

This is a **Python & Data Science course** repository for a sophomore-level university class (大二下 Python与数据科学). It contains 10 lab exercises spanning Python fundamentals through applied machine learning, plus course slides, a study guide, and a final project template.

├── Lab6/              # 数据挖掘入门分类 (scikit-learn, Random Forest)
├── Lab7/              # 蛋白质功能预测 (XGBoost, feature engineering, bioinformatics)

Each Lab directory is organized into:
- **`code/`** — Python source files
- **`data/`** — Input data files (CSV, TXT, Parquet, XLS, images)
- **`output/`** — Results generated by running code (predictions, reports, logs)
- **`README.md`** — Knowledge document explaining concepts from a beginner's perspective

Original lab materials (`.zip` files) are centralized in `实验原始资料/`.

## Learning Progression

## Learning Progression

The labs follow a clear pedagogical arc:

1. **Lab 1–2**: Python syntax, control flow, data structures (strings, lists, dicts), functions, lambda, map/filter/reduce
2. **Lab 3**: File I/O, CSV/JSON parsing, os module operations
3. **Lab 4**: Object-oriented programming (classes, inheritance, packages with `__init__.py`)
4. **Lab 5**: Scientific computing stack — NumPy arrays, pandas DataFrames, Matplotlib/Seaborn plotting
5. **Lab 6**: Machine learning pipeline (scikit-learn) — train/test split, feature scaling, Random Forest classifier
6. **Lab 7**: Advanced feature engineering (amino acid composition, dipeptide, k-space features) + XGBoost
7. **Lab 8**: Text classification — TF-IDF vectorization, logistic regression, Parquet data
8. **Lab 9**: Image classification — PIL image loading, PCA dimensionality reduction, SVM
9. **Lab 10**: Web scraping — BeautifulSoup, requests, regex pattern matching

## Running Code

Scripts are in `code/` subdirectories — run from the repository root:

```bash
python LabN/code/filename.py
```

Some scripts reference data files relative to the repo root (e.g., `Lab7/code/Lab7.py` reads `Lab7/data/ProSeqs_Train.txt`). Always run from the repository root directory.

Each Lab has a `README.md` knowledge document explaining concepts from a Python beginner's perspective.

Jupyter notebooks (`.ipynb`) are available in `课件/`.

## Common Patterns

- **Data loading**: CSV via `pd.read_csv()`, text via `open()`, Parquet via `pd.read_parquet()`
- **Model pipeline**: Scale features → train classifier → predict → save to `preds.txt` or `predictions.txt` (one label per line)
- **Output format**: Most ML labs save predictions as text files with one prediction per line (integer or float)
- **Module structure** (`Lab4/`): `mypack/` shows the canonical Python package layout (`__init__.py`, subpackages)
